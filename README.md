# Распределённые вычисления

Лабораторные работы на языке Си.

- `lab0/pa1` — межпроцессный обмен сообщениями через неименованные каналы,
  синхронизация STARTED/DONE.
- `lab1/pa6` — распределённое взаимное исключение по алгоритму обедающих
  философов Чанди—Мисры.
- `tests` — проверки IPC и запуска процессов.

Задания находятся в PDF в корне проекта. Рядом лежат исходные архивы starter
code и их распакованное содержимое. Архивы для сдачи — `lab0/pa1.tar.gz`
и `lab1/pa6.tar.gz`.

Сборка рассчитана на Linux. Команды приведены в [lab0](lab0/pa1/README.md)
и [lab1](lab1/pa6/README.md).

Проверки из корня проекта:

```sh
sh tests/run.sh
```
