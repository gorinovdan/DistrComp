# Лабораторная работа № 1

Взаимное исключение по алгоритму обедающих философов Чанди—Мисры.
Между каждой парой дочерних процессов есть одна вилка. Для входа в критическую
секцию процесс собирает все свои вилки; после выхода помечает их грязными
и отдаёт по отложенным запросам. Родитель в распределении вилок не участвует.

Сборка и запуск в 64-битном Linux:

```sh
clang -std=c99 -Wall -pedantic *.c -L. -lruntime -o pa6
LD_LIBRARY_PATH=. ./pa6 -p 3 --mutexl
```

Без взаимного исключения:

```sh
LD_LIBRARY_PATH=. ./pa6 -p 3
```

Параметр `-p` задаёт число детей от 0 до 15. Каждый ребёнок выполняет
`local_id * 5` итераций. При `--mutexl` каждый вызов `print()` выполняется
в отдельной критической секции. IPC использует неблокирующие каналы.

Журналы: `events.log` и `pipes.log` в текущем каталоге.
Архив для сдачи: `pa6.tar.gz`, внутри — каталог `pa6` и `libruntime.so`.

Проверки из корня проекта: `sh tests/run.sh`.
