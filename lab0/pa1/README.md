# Подготовительная работа

Обмен сообщениями между процессами через неименованные каналы. Для каждой
пары процессов создаются два однонаправленных pipe. Дочерние процессы
синхронизируются сообщениями STARTED и DONE, родитель принимает их и ждёт
завершения детей.

Сборка и запуск в Linux:

```sh
clang -std=c99 -Wall -pedantic *.c -o pa1
./pa1 -p 3
```

Параметр `-p` задаёт число дочерних процессов от 0 до 15. Журналы записываются
в `events.log` и `pipes.log` в текущем каталоге.

Архив для сдачи: `pa1.tar.gz`, внутри — каталог `pa1`.

Проверки из корня проекта: `sh tests/run.sh`.
